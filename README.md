# AcademiaTalk

Platform diskusi dan berbagi ilmu berbasis web, tempat pengguna bisa bertukar pikiran, ide, dan pengetahuan.

## Fitur
- Halaman beranda, tentang, diskusi, pembelajaran, dan kontak
- [fitur lain, misalnya login, membuat topik diskusi, komentar]

## Teknologi
- CodeIgniter 4 (PHP)
- MySQL
- HTML, CSS, JavaScript

## Tampilan
![Beranda AcademiaTalk](screenshot-beranda.png)

## Cara Menjalankan
1. Clone repository ini
2. Jalankan `composer install`
3. Salin file `env` menjadi `.env`, lalu atur `baseURL` dan pengaturan database
4. Impor database [nama-file.sql, kalau ada]
5. Jalankan `php spark serve`, lalu buka `http://localhost:8080`
